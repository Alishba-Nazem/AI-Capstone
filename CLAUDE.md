# AI Development Rules

Always write clean code.

## Project-Specific Rules

1. Forms must include automated tests for validation and important user interactions.

2. Validation logic must be separated from UI components where practical.

3. Every form control must have a visible, associated label and appropriate accessibility attributes.

## Stack

- React
- TypeScript
- Vite
- Node.js

## Coding Style

- Use TypeScript
- Write clean code
- Prefer reusable components
- Use descriptive names
- Follow React best practices
